# Библиотека — сайт на Spring Boot

Читатель и библиотекарь, каталог с обложками и аннотациями, выдачи и автоматические штрафы.
Стек: Java 17+, Spring Boot 3 (Web, Security, Data JPA, Thymeleaf), PostgreSQL, Gradle.

## Запуск
1. Установите JDK 17 или новее и PostgreSQL.
2. Создайте пустую базу: `CREATE DATABASE library;`
3. В `src/main/resources/application.properties` укажите свой логин и пароль PostgreSQL.
4. Откройте папку проекта в IntelliJ IDEA (File → Open → выбрать `build.gradle` → Open as Project).
   Если IDEA спросит про Lombok — включите Annotation Processing
   (Settings → Build, Execution, Deployment → Compiler → Annotation Processors → Enable).
5. Запустите класс `LibraryApplication`. Сайт: http://localhost:8080

При первом запуске таблицы создаются сами, а база заполняется тестовыми данными.

## Пробные аккаунты
| Роль | Почта | Пароль |
|---|---|---|
| Библиотекарь | admin@library.local | admin123 |
| Читатель | reader@library.local | reader123 |
| Читатель с просрочкой и штрафами | ivan@library.local | reader123 |

Новые читатели регистрируются сами на странице «Создать аккаунт читателя».

## Как добавить обложки и аннотации
Войдите как библиотекарь → «Издания» → «Изменить» (или «Добавить издание»).
Там есть загрузка обложки (PNG/JPG/WebP/GIF до 5 МБ, лучше вертикальная 2:3) и поле «Аннотация».
Файлы обложек сохраняются в папку `uploads/covers` рядом с проектом.
Пока обложки нет, показывается фиолетовая заглушка с названием.

## Правила (меняются в application.properties)
- `library.loan-days=14` — срок выдачи, дней
- `library.fine-per-day=10` — штраф за каждый день просрочки, ₽
- `library.max-active-loans=5` — сколько изданий может быть на руках одновременно

Штраф считается автоматически: дни просрочки × тариф. Пока издание не возвращено, сумма растёт.
Пока у читателя есть просрочка или неоплаченный штраф, новые выдачи ему недоступны.

## Структура
- `model` — сущности (пользователь, издание, выдача)
- `repository` — доступ к базе
- `service` — вся логика (`LibraryService`), загрузка обложек, тестовые данные
- `web` — контроллеры (вход, каталог, читатель, библиотекарь)
- `config` — безопасность и раздача обложек
- `resources/templates` — страницы, `resources/static/css/style.css` — дизайн
